# Salary evidence and estimator revision 4

Tim authorized implementation and live deployment on 2026-11-02. This changes evidence processing, not the canonical geography or PAY_WORTH rules at policy blob `cf8e4265939e70cce6c10d9968e2cee83b490df7`.

1. Exact posted annual base pay precedes estimates. Active FORGE and third-party estimates enter a durable, rotating review; failures retain the saved range and back off. Reviews are bounded by the existing run time, source-read budget and Writer envelope, rather than a five-job limit. Workday accepts explicit annual USD base-salary structures, then salary-labelled full-description evidence. Exact employer JSON-LD can use a salary-labelled description if structured pay is absent. Employer wording such as “estimated base salary” is employer disclosure, not a third-party estimate. Multiple conflicting pay bands, total compensation and hourly amounts are not promoted. Existing employer search routes include Boeing, Lockheed Martin and Baxter. A newly found URL requires matching employer/title/site and a matching employer requisition before replacing target pay; search results alone cannot establish identity.
2. An explicitly recorded client employer is used for estimates; BioSpace, VetJobs and known board/unnamed-agency labels cannot form same-employer cohorts. This attribution does not rewrite canonical company identity. Engineering/manufacturing-technology and supply-chain work are classified before generic manufacturing/operations words. Explicit company/site/role context and clearance facts retain sourced provenance. Missing context is unknown, not an assumed premium.
3. Compatible employer and independent peer postings are blended. Each employer’s aggregate influence is capped; employer-cohort and peer-cohort weighted medians are combined with support `n/(n+1)` for `n` distinct employer postings. A single posting gets half the support rather than excluding all peers. Context conflicts, posting deduplication, source age, level, specialty and executive scope remain checked. State ratios remain the existing BLS-based bounded adjustments; no fixed company/defense premium or 15% level uplift is introduced.
4. If exact role-family comparables are unavailable, a director-and-up fallback uses at least three distinct employer-posted roles at the same leadership level/function/specialty/executive scope. Its broader-family uncertainty is LOW. Ordinary manager postings cannot substitute for director/VP evidence. If this evidence is unavailable, the existing explicitly labelled required BLS fallback remains; no unsupported executive wage is invented.
5. `SALARY_BASE_LOW/HIGH` define the range; `SALARY_MIDPOINT=(low+high)/2`; `SALARY_SCORE_POINT=low+0.75*(high-low)`. Writer and viewer derive the latter values from the accepted range, ignoring a conflicting cached midpoint or supplied scoring point. The map-based NEED formula and published scoring settings remain unchanged. Existing salaries migrate through normal active review/recalculation with fresh row guards and normal Writer verification, not direct master edits. Applied, rejected, declined and other protected rows remain excluded from salary research.

Validation includes exact-source identity, employer “estimated” wording, conflicting ranges, annual/currency safeguards, attribution, leadership fallback, stale models, concurrent row changes, midpoint/scoring separation and Writer/viewer parity. Leave-one-posting-out diagnostics exclude target aliases; they are not a promised future accuracy improvement. On the available audit cohort the broader model increases estimable coverage, while midpoint errors remain approximately the same. Exact posted-pay recovery is the strongest correction; no numeric accuracy percentage is claimed.

1. THEME RULES
--------------
- Futuristic military HUD. Black / neutral grey only; NO blue-tinted charcoal.
- Emphasis by contrast, weight, spacing; restrained status colour. One colour = one meaning everywhere.
- Signals are ACCENTS: 2-3 px left bar or border, never a background fill (exception: primary buttons).
- Nothing glows at rest. Glow only on focus, processing, edge traces, lock-on.
- Components reference tokens only; lint rejects raw hex, raw durations, raw easings, and any radar token.

6. MOTION (Section 12)
----------------------
Durations: instant 0 · fast 120 (hover/press/focus) · base 240 (panel/tab/toast) · lock 320 ·
  materialize 400 · sweep 600 · roll 800 · boot 1200 total · breathe 1600 loop · fit 600 · stagger 18/row (cap 30).
Easings: out cubic-bezier(.16,1,.3,1) · in (.7,0,.84,0) · inout (.65,0,.35,1) · snap (.34,1.56,.64,1) · linear.
Catalog M-01..M-19: boot (grid fade -> panels slide -> brackets draw; input live at t=0) · panel slide
  24 px + fade · job-detail scanline + pixel dissolve · map auto-fit · lock-on (brackets 2x->1x, reticle
  rotates 90°) · pin drop 12 px snap 240 · KPI roll 800 · new-row cyan wipe · row stagger 6 px · score
  ring draw 600 · tab slide 240 · Writer states (amber breathe 1600; cyan processing; red shake 3 x 4 px
  300 ms then steady + Retry) · toast receipt slide-up · hover 1 px cyan trace 120 · ticker 40 px/s,
  pause on hover · map fullscreen · mobile swipe (35% threshold, spring back) · recalc bar + ◌ cross-fade ·
  panel loading brackets + scanline "ACQUIRING…".
Guardrails G1–G6: never blocks input; never hides true state (final values in DOM immediately; write
  motion only from state-machine events); 60 fps, animate transform/opacity/filter/small stroke-dashoffset
  only; Reduce motion toggle (off by default: loops -> 0, slides -> fast fades, fit -> 120 ms);
  colour follows meaning; nothing flashes > 3x/s (WCAG 2.3.1).

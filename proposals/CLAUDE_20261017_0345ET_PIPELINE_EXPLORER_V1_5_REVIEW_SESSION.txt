3. CONTAINMENT FIX (designed, tested in isolation, NOT deployed)
---------------------------------------------------------------
Server (Code.gs):
  - mergeState_: ignore incoming rulings; union seen (keep max); union event incidents by id, never delete;
    status follows the client's own rule (only ACTIVE yields to a later known state; equal status -> higher
    attempts); unknown status never replaces a known one; eventIds unioned and deduplicated.
  - writeState_: LockService wait 30 s; refuse unreadable/non-object stored file (STATE_UNREADABLE, no write);
    write PIPELINE_EXPLORER_STATE.json.prev with prior content first; write merged state; read back
    (STATE_READBACK_MISMATCH on mismatch).
  - doPost: `if (req.action==='state') return out_(writeState_(req.state||{}));`
  - Porting: paste functions as plain declarations; drop the `require` line (Apps Script shared global scope).
    Requires V8 runtime (Object.assign).
Client (pipeline.html):
  - openRow() stops calling syncStateUp().
  - syncStateUp() sends {seen, incidents} only.
  - Check `.then(r => r.ok)`; visible pill: ◷ pending / ⊗ failed / ✓ synced HH:MM.
  - Local revision counter: increment on every change, record revision sent, show ✓ only when confirmed
    revision == current revision (prevents a false ✓ when changes happen mid-flight).
  - localStorage already holds all seen/incidents and every post carries the full set, so no separate queue.

4. REQUIREMENTS HF-01..HF-19 (priority · phase · acceptance)
------------------------------------------------------------
HF-01 One score, one meaning (P0, Ph1). Single scoring record {value, score type, rule/model rev,
  computed-at, evidence status}; queue, detail, map, compare render from one selector; one display
  name; alternative/historical scores labelled. Key memoized config cache on rules/weights version hash.
  ACCEPT: identical value + band for same job/type/version in every view (100%).
HF-02 Counts that reconcile (P0, Ph1). Counter registry: population, filters, window, source for every
  tile/header count; tiles clickable and filter queue to exactly that population; scope labels
  (live / cohort / archive; "Applied – all time" vs "Applied – this view").
  ACCEPT: every counter matches its documented query; tile click count == rows shown.
HF-03 Decisions that show the truth (P0, Ph1). One click starts a write (no Save for routine decisions).
  States queued -> processing -> confirmed | failed | superseded; idempotency key per decision; receipt +
  Undo under buttons; queued shows wait time + next Writer blackout; failed keeps payload + Retry;
  Decline visually separated from Pursue, reason code required. Writer latency 20–45 min is normal.
  ACCEPT: fault injection (timeout, 5xx, duplicate ack, blackout): 0 false successes, 0 dropped, 0 dupes.
HF-04 Behavioral surprises (P1, Ph1–2). Fix TypeErrors 1320/1326; Compact works or is removed;
  LOCAL vs SHARED separated, shared changes warn + confirm; duplicates removed; Writer banner debounced
  (only after 2 failed checks or 20 s grace; health = worst current fault); opening a job never writes.
  ACCEPT: console clean across 5 task scripts; 0 false-alarm banners on load; 0 writes on job open.
HF-05 Context preservation + conflict guard (P1, Ph2). Refresh keeps selected job, filters, sort,
  scroll; new/changed rows highlighted not silently reordered; decision carries record version seen at
  open, mismatch -> warn + superseded, never overwrite. ACCEPT: selection retained after refresh 100%.
HF-06 Navigation (P1, Ph2). Map permanent panel; fullscreen below tab bar with ✕ Close + Esc; auto-fit;
  selection synced with queue; rail pushes (never overlays) content; pin toggle with visible ⇤ Unpin.
  ACCEPT: close found unaided by Tim; 0 overlay-covered content.
HF-07 Density preserved (P2, Ph3). 11-column default; adjustable widths; column priority; no horizontal
  overflow for title, company, location, score, posted pay, age; nothing clipped mid-word; posted pay +
  age next to score. ACCEPT: 0 priority-column overflow.
HF-08 Readable labels (P2, Ph3). SALARY_BASE_EST -> "Base pay (est.)"; FLEX_CLASS -> "Degree flex";
  RESOLVED/APPLIED_CONFIRMED -> "Applied – confirmed". Raw codes only in Layer 4 (debug detail).
HF-09 Score rationale (P2, Ph3). One plain-English line by every score (e.g. "Startup ramp role,
  $200–250K posted, degree required – flex"); breakdown + uncertainty one click away.
  ACCEPT: score drivers understood <= 10 s median.
HF-10 Change summary (P2, Ph3). Strip "Since your last review: N new · N scores changed · N Writer
  retries needed · N queued · N provisional", each item clickable.
HF-11 Chart integrity (P2, Ph3). Case-insensitive source normalisation; persist decline reason codes.
HF-12 Personalization (P3, Ph4). Learns from overrides; advisory, explains itself, reversible; never
  alters canonical rules, applies to jobs, or decides.
HF-13 Phone scope (P2, Track M). Layer-1 counts, change summary, queue, selected job, decide/undo.
  Targets >= 44 pt. Rule/settings editing desktop only.
HF-14 Baseline first (P0, Ph0). Time 5 tasks on current build before any change; repeat each phase.
HF-15 Motion system (P2, Ph2–3). Named duration/easing tokens; catalog M-01..M-19 (§7); no radar.
  Guardrails: never blocks input, never hides true state, GPU-only 60 fps, flash-safe (WCAG 2.3.1);
  Reduce-motion toggle in Local preferences, off by default. Write-state motion driven ONLY by
  state-machine events. ACCEPT: 0 input blocked; p95 frame <= 16.7 ms; every animation maps to a token;
  write-state motion never precedes the state event.
HF-16 Map panel — Tim's rule (P1, Ph2–3). Selected job, else filtered set; score-band pins; two-way
  selection sync; hover cards; animated auto-fit; fullscreen with ✕ + Esc; targeting look kept.
  ACCEPT: pin set == filtered rows (or the selected job) 100%; sync 100%; 0 radar/ring/cluster elements.
HF-17 2560 x 1440 layout (P2, Ph3). Rail 56 px (push) + three zones: table 1112 · map 800 ·
  workspace/job drawer 508; sub-tabs, KPI tiles, change strip, event ticker.
  ACCEPT: 11/11 columns and >= 30 rows visible, no horizontal scroll, 0 clipped priority cells.
HF-18 Mobile redesign (P2, Track M). iPhone 18 Pro (assumed 402 x 874 pt — lay out from safe-area
  insets, not constants). Portrait: cards with swipe decisions + haptics (35% threshold; Decline needs
  long-press + confirm), tab bar, full-bleed map + bottom sheet. Landscape: split view. Desktop-mode
  switch with state persisting both ways. Perimeter: 24 pt side padding beyond safe area, 36 pt in corner
  zones, controls >= 16 pt above the home indicator; camera keep-out top (portrait), left or right
  (landscape, whichever side the island is on). Targets >= 44 pt.
  ACCEPT: Undo 100%; state kept across switch 100%; 0 tap targets in keep-out zones in portrait and
  both landscape rotations (simulator-checked).
HF-19 Scoring page + geo map (P1, Ph1–3). Honest total 100% = 70 local + 30 shared FLEX (FLEX as an
  explicit locked row); LOCAL/SHARED badge per card; shared saves confirm + Writer receipt + undo; live

  stale scores everywhere, band changes held until recalculated; salary curve drawn (190k/240k/300k ->

5. PHASES
---------
PHASE 0 — BASELINE (HF-14). No product changes.
  Script 5 tasks: (a) find job needing action, (b) state main score drivers, (c) disposition a simple job,
  (d) reconcile Applied count, (e) find previously selected job after refresh. >= 3 sessions; record time,
  errors, extra navigation, scrolling, 1–7 ease. Snapshot score/band/label for 20 jobs across table,
  detail, map, compare. Snapshot every counter + apparent query. Capture console, selection latency,
  raw codes visible, Writer queue depth + blackouts. Gate: discrepancy register signed off by Tim.

PHASE 1 — DATA INTEGRITY (HF-01, 02, 03, 04, 19) — FIRST. Tasks T-01..T-07 + T-17.
  1. Weight totals: show 100% = 70 local + 30 shared FLEX on Settings and in Fit & Score (T-04).
  2. Score drift: record carries model rev + computed-at + provisional flag; ◌ on every stale score in
     table, drawer, map, compare; surface recalc progress 185/603 pending at shared rev 24; root-cause
     Anduril 77 -> 72 -> 59 (stored FLEX vs live policy); no rating change on view without an event
     (T-01..T-03).
  3. Cross-view counts: counter registry + scope labels; reconcile Applied 84/26, Declined 0/56/57,
     Employer rejected 0/2/7, intake 0/138, "0 need you"/50 (T-05).
  4. Writer banner flapping: debounce (2 failed checks or 20 s grace) (T-07).
  5. Transient unverified write on job open: opening never writes; seen-state local, or explicit +
     receipted; footer "unverified" opens receipts (T-06).
  6. Local vs shared save scope: LOCAL / SHARED labelling on save paths; shared requires confirm (start
     here, full badges in T-12).
  7. Decision state machine + receipts + Undo + idempotency; Decline reason code (T-17). Fix TypeErrors.
  Gate: cross-view consistency 100%; counter reconciliation 100%; fault injection 0/0/0; console clean;
  ◌ on 100% stale; weights total = visible sum; selection latency <= 0.7 s (no 32 s lag regression).

PHASE 2 — WORKFLOW + MAP RULE + MOTION CORE (HF-04, 05, 06, 15, 16, 19). T-08..T-14, T-20..T-22, T-24.
  Compact fix/remove; context preservation + conflict guard; map permanent panel showing selected/filtered
  set with animated auto-fit, clusters removed; fullscreen ✕ + Esc; rail push + Unpin; dedupe entry
  points; LOCAL/SHARED badges on every settings card (scoring, target companies, rules, display,
  documents); shared-change guard; impact preview; path aliases + not-found notice; bulk actions (SELECT
  VISIBLE, AI DISCOVER, MARK SEEN, catch-up, acknowledge) separated from filters with confirm + count +
  receipt; single Writer connection entry, credentials only behind explicit reveal; radar purge; motion
  tokens shipped.

PHASE 3 — COGNITIVE + VISUAL + 2560 (HF-07..11, 15, 17, 19). T-14..T-16, T-18, T-19.
  11-column readable 2560 preset, readable labels, rationale line, change strip, source normalisation,
  full motion catalog, palette tokens applied via one token file, scoring page redesign (salary curve
  chart, geo map editing, authority notes).

PHASE 4 — ADAPTIVE (HF-12). Log overrides vs recommendation with persisted reason codes; opt-in,
  explainable, reversible personalisation subordinate to canonical rules and Tim's decisions.

TRACK M — MOBILE (HF-13, HF-18). T-23. Starts after Phase 2 gate, parallel with Phase 3.
  Inset tokens; camera keep-out both orientations; lifted bottom controls; simulator check both
  landscape rotations; HF-14 tasks timed on phone.

Cross-cutting: Writer queue 20–45 min normal (timings measure time-to-decision); no rollout inside a
blackout; bulk bot updates summarised in change strip / ticker, not individually animated; further
layout changes need Tim's explicit approval.

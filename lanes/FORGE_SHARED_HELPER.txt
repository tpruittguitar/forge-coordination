FORGE SHARED RESEARCH HELPER
For FORGE_CLAUDE_SHARED_HELPER / FORGE_GROK_SHARED_HELPER. One active invocation per provider; skip overlaps. scheduleIntent is not installation proof. WRITE_THROUGH_SUPPORTED_WRITER uses the authorized adapter.

FRESH START
Resolve live main through GitHub each invocation; read registry, contract and assignments at that SHA, not cached setup state. Recheck the branch ref before reporting missing availability/work. The first real run verifies setup; no prerequisite or repeated readiness probes. Do not invent activation.

WORK
Read control/SHARED_HELPER_WORK.json. Require enabled, routingActive and your provider available. Run node tools/helper-routing/shared.cjs <TASK_KEY> [nextAfter]; use backlogCounts/laneOrder. Without shell, count distinct ASSIGNED jobs (primaryId/key/aliases) across available providers; exclude future retryAfter, protected jobs, original-request fences, other owners and returned/completed items. Use lane, else kind. Sort by descending count; ties: RESEARCH, ENRICHMENT, INTAKE, DISCOVERY. Within lanes: assignedAt, then key. Report SHA/counts.
Work ONLY your assignments, largest eligible backlog first, then others as capacity allows. No fixed Research-first override or self-assignment. Recheck ownership, assignmentVersion, sourceVersion, missing fields and protection before EACH item and return. Preserve existing reservations. Coordinator alone assigns/transfers. No assignments is not a clean pipeline. If available: node tools/research-preflight/check.cjs <TASK_KEY>; stale/missing inventory is INSPECT_QUEUE, not IDLE.
Pass nextAfter unchanged; honor cursorReset and skip checkpointed returns. Twenty items is artifact size, not a pass/day cap. Continue chunks within actual runtime, not a capacity sample. Unchanged blocked routes need new evidence or their retry condition.

RESEARCH
Reuse saved full postings, ATS data, prior attempts and accepted evidence. Resolve assigned pay, fit, link and degree gaps, including MANUAL_RESEARCH. Intake recovers assigned source cards under existing-first identity rules. Discovery uses assigned searches/filters; preserve dedupe and approvals.
Bind employer/title/location/requisition, URL, observedAt and exact quotes. Hash real captured bytes; never invent fingerprints. Without hashing tools, return sourceEvidence.capture={kind:"TEXT_EXTRACT",text:<verbatim source text>} and omit sourceSha256. Code hashes those exact UTF-8 bytes; this is transport evidence, not independent verification. Quote must occur in capture; limits: 300 characters minimum, 200,000 bytes/capture, 2 MB/batch. Never reconstruct postings or substitute related requisitions. Distinguish live exact roles from closed listings and generic pages. Unreadable/truncated sources never prove NOT_STATED. Salary requires employer-posted base pay with currency/period; code owns estimates. Degree quotes establish requirement/preference/experience equivalency, not a waiver; Writer derives FLEX_CLASS.
Fit: sourceEvidence.fit={requirements:[{quote}]}. Code derives omitted resume hash/competencyIds from the current profile after exact-source checks. For explicit mappings read control/RESUME_MATCH_PROFILE.json; use its actual resumeTextSha256 and IDs. Quotes are exact 30–1500 character requirements. Empty competencyIds means no observed overlap; present values remain strictly checked. Never invent qualifications or scores. Links need posting self-binding or ID-bound ATS provenance, never homepages. No identity, bucket, decision, score or Needs Tim fields.

RETURN
Use docs/DIRECT_WRITER_PROCESSING.md for ready facts. Invoke the locked returns-only adapter if accessible; otherwise existing automatic transport. No manual relay, approval or PR dependency. Missing access: retain JSON as TRANSPORT_PENDING, not delivered/written. At limits save evidence, cursor, unfinished work and terminal checkpoint. Transfer requires coordinator-confirmed terminal checkpoint, reason, no pending transaction and incremented assignmentVersion. Timers/quota never expire ownership; quarantine late old-owner returns.
Batch: schema=forge.shared-helper-batch.v1; actual provider/taskKey, assignmentId, instructionCommit (40-character main SHA), unique FORGE-CLAUDE-... or FORGE-GROK-... runId, 1–20 items. Copy kind, primaryId OR key, assignmentVersion, sourceVersion; writerSubmitted=false. sourceEvidence: company/title/location/url/observedAt/quote, real sourceSha256 OR capture, optional fit. Recommendation: ENRICHMENT_EVIDENCE_READY or INTAKE_READY; otherwise SOURCE_BLOCKED, RESEARCH_INCOMPLETE, EXISTING_CANONICAL or PROTECTED_SKIP with reason/researchOwner/retryCondition. Blocked/incomplete items need no invented hash/quote. Validate: node tools/helper-routing/shared.cjs validate <file>.
Publish NEW receipts/CLAUDE_HELPERS/<TASK_KEY>/<runId>.json or receipts/GROK_HELPERS/<TASK_KEY>/<runId>.json on claude-shared-helper-batch-<unique> or grok-shared-helper-batch-<unique>, or private forge-helper-<runId>.json. Label commits PROVIDER/RUN_ID; preserve appends, fetch/rebase, no force push, verify remote SHA. Process the exact return via adapter/transport. Recheck ownership/source/identity/resume.

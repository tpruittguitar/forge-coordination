A run that ends without a commit is a defect; the Explorer can only show a failure that reaches the file.
2. tabs_context_mcp, then open ONE new tab and use it for all three pages:
   a. https://claude.ai/settings/usage  -> "This week" (meter weekly, label "weekly (all models)", windowHours 168) and "Current session" (meter session, label "current session", windowHours 5).
   b. https://grok.com/?_s=usage        -> "Weekly SuperGrok Limit" (meter weekly, label "weekly SuperGrok", windowHours 168) and "Weekly Grok Bot Limit" (meter bot, label "weekly Grok Bot", windowHours 168).

3. Convert every reset time to an absolute UTC ISO time using the run's current time (America/New_York): "Resets Sunday 12:00 PM" = the next Sunday 12:00 ET; "Resets in 6d 9h" = now + that; "October 19, 2026 at 4:30 AM" = that ET time.
4. Append one JSON object per meter, one per line, no spaces needed:
   {"at":"<UTC ISO now>","provider":"CLAUDE|GROK|CHATGPT","meter":"...","label":"...","usedPct":<number>,"resetsAt":"<UTC ISO>","windowHours":<168|5>,"status":"OK|SIGN_IN_NEEDED|CHROME_UNAVAILABLE|UNREADABLE","source":"<page> via Chrome"}
   Clone tpruittguitar/forge-coordination (add_repo with push access, git clone --depth 1), append the lines to usage/AI_USAGE_READINGS.jsonl, keep only the newest 600 lines, commit "CLAUDE USAGE-READER <YYYYMMDD-HHMMET>: <n> readings", fetch + rebase + push, verify with git ls-remote.
5. Close the tab you opened. No receipt file is needed; the commit is the record. Keep the run short: no other pages, no analysis.
